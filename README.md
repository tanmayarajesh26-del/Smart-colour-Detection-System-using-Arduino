# Smart-colour-Detection-System-using-Arduino
Arduino project for real-time color detection using a TCS3200 sensor with LED-based visual indication.
# Arduino Color Sensor Project

## Components Used
- Arduino UNO
- TCS3200 Color Sensor
- LEDs (Red, Green, White)
- 330Ω resistors

## Working
This project detects the color of an object and turns on the corresponding LED.

- Red object → Red LED
- Green object → Green LED
- Blue object → White LED
